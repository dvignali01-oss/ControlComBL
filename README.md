ControlComBL 🚀

Aplicação web para gestão de vendas, metas e comissões.

🌐 "Acessar aplicação" (https://control-com-bl.vercel.app/) · 💻 "Código-fonte" (https://github.com/dvignali01-oss/ControlComBL)

Sobre o projeto

O ControlComBL é uma aplicação web desenvolvida para facilitar o controle de vendas, a gestão de clientes e o acompanhamento de resultados comerciais.

O sistema reúne ferramentas para organizar informações, calcular indicadores e acompanhar metas em um único ambiente.

Funcionalidades

- 📊 Dashboard com indicadores de desempenho.
- 📝 Cadastro e gerenciamento de vendas.
- 👥 Carteira de clientes.
- 🎯 Acompanhamento de metas comerciais.
- 💰 Cálculo e simulação de comissões.
- 📓 Bloco de notas.
- 📤 Relatório de fechamento comercial.
- 💾 Armazenamento local com LocalStorage.

Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Lucide Icons
- Google Fonts
- Vercel

Como executar localmente

1. Clone o repositório

git clone https://github.com/dvignali01-oss/ControlComBL.git

2. Entre na pasta do projeto

cd ControlComBL

3. Abra o arquivo "index.html" no navegador.

Não é necessário instalar dependências com npm para executar a versão estática do projeto.

Armazenamento de dados

Os dados são armazenados localmente no navegador por meio do LocalStorage. Por isso, não há sincronização automática entre dispositivos.

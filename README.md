ControlComBL — Controle de Vendas e Comissões

Desenvolvido por Diego Vignali

🔗 Aplicação: https://control-com-bl.vercel.app/

Sobre o projeto

O ControlComBL é uma aplicação web desenvolvida para facilitar a organização de informações comerciais, o acompanhamento de clientes, o controle de vendas e o monitoramento de metas.

A ideia surgiu da experiência prática na área de vendas e da identificação de oportunidades para utilizar a tecnologia na resolução de problemas do cotidiano profissional.

O projeto representa minha experiência prática com desenvolvimento web e meu interesse em criar soluções digitais úteis, funcionais e orientadas às necessidades reais dos usuários.

Funcionalidades identificadas

- Organização de informações de clientes e vendas.
- Pesquisa de clientes por nome.
- Alteração do status de vendas.
- Configuração de metas por quantidade e valor.
- Notas rápidas.
- Armazenamento de informações no navegador.
- Interface interativa para acompanhamento das informações.

Esta lista considera as funcionalidades identificadas nos trechos de código analisados. Outras funcionalidades poderão ser acrescentadas após a revisão do código completo.

Tecnologias

- HTML5 — estrutura da aplicação.
- CSS — estilização e apresentação visual.
- JavaScript — funcionalidades e interatividade.
- LocalStorage — armazenamento local de informações no navegador.
- Vercel — publicação e hospedagem da aplicação.

Objetivo do projeto

Aplicar conhecimentos de programação para desenvolver uma ferramenta que facilite a organização de informações comerciais e contribua para uma rotina de trabalho mais eficiente.

O projeto também faz parte da minha evolução profissional na área de tecnologia, unindo experiência prática em vendas, desenvolvimento web e interesse crescente por análise de dados.

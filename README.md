# ControlComBL
ControlComBL — Controle de Vendas e Comissões

Sobre o projeto

O ControlComBL é uma aplicação desenvolvida para facilitar o controle de vendas, o acompanhamento de resultados e o cálculo de comissões.

O projeto surgiu da necessidade de tornar essas atividades mais organizadas, práticas e eficientes, reduzindo o trabalho manual e facilitando a visualização das informações.

Funcionalidades

- Importação de planilhas de vendas.
- Organização e acompanhamento de vendas.
- Cálculo de comissões com base nas regras configuradas.
- Geração de relatórios para análise dos resultados.
- Exportação e compartilhamento de informações pelo WhatsApp.

Objetivo

O objetivo do ControlComBL é simplificar a rotina de profissionais de vendas e ajudar a tornar o acompanhamento de resultados e comissões mais transparente e organizado.
